Staff notes

This page previews the hunting and fishing guide. To place it on a trlibrary.com page, paste this into a code block:

<div id="trpl-huntfish"></div>
<script src="https://huntfish.labs.trlibrary.com/huntfish.js" defer></script>

Add data-heading="off" to the script tag when the page already has its own heading. Other views: data-view="check", "map", "seasons", "fishing", "licenses", "compact".

Compact "open today" card (sidebar or homepage)

<div id="trpl-huntfish-mini"></div>
<script src="https://huntfish.labs.trlibrary.com/huntfish.js" data-view="compact" data-target="#trpl-huntfish-mini" data-more="https://www.trlibrary.com/..." defer></script>

Full-screen map for phones

huntfish.labs.trlibrary.com/map/ opens the check button, map and seasons full screen. It can be added to a phone's home screen, and "Save this area for offline" keeps the map working with no signal.
